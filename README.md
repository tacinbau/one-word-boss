One word for the boss: **Delegator**.

Why this word: every boss delegates — the work flows down, the credit flows
up. It is one real word, funny on its own, true in any workplace, and fresher
than the first word anyone reaches for.

`main.ts` writes the word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
Run it with `node main.ts`. No dependencies, no network.
